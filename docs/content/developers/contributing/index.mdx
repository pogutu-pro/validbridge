# Engineering Workflow

ValidBridge is proprietary software developed by [Stratnovo Systems](https://stratnovo.co.ke). This section is for Stratnovo engineers and authorised partners who have access to the source repository.

<Callout>
Using ValidBridge and have found a bug or want a feature? Email [support@validbridge.co.ke](mailto:support@validbridge.co.ke) or use **Help → Report Issue or Feedback** in the app — you do not need repository access.
</Callout>

## Getting Started

1. **[Set up your development environment](/developers/contributing/dev-environment)** -- Get a local instance of ValidBridge running from source.
2. **[Review the engineering guidelines](/developers/contributing/guidelines)** -- Our workflow, code style, and expectations for pull requests.

## Finding Work

Work is tracked in the private ValidBridge issue tracker. Discuss new features with the product team before starting on them.
