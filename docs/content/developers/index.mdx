# Developers

Welcome to the ValidBridge developer documentation. This section covers the architecture and API of ValidBridge, the learning platform built by [Stratnovo Systems](https://stratnovo.co.ke).

## Project Structure

ValidBridge is organized as a monorepo containing four main applications:

| App | Technology | Description |
| --- | --- | --- |
| **web** | Next.js (React) | Frontend web application |
| **api** | FastAPI (Python) | Backend REST API |
| **collab** | Hocuspocus | Real-time collaboration WebSocket server |
| **cli** | Commander (Node.js) | Command-line interface for development and management |

All four apps live under the `apps/` directory of the (private) ValidBridge repository.
