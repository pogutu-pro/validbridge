# Enterprise Edition

The ValidBridge Enterprise Edition (EE) adds features to ValidBridge, the commercial learning platform by [Stratnovo Systems](https://stratnovo.co.ke). It includes additional features designed for organizations that need advanced identity management, compliance tooling, and support for industry-standard learning content formats.

## Licensing

ValidBridge is proprietary software licensed by Stratnovo Systems. Enterprise features are available under an **Enterprise plan or licence**.

- **On-premises deployments** — Enterprise features require a valid licence key issued by Stratnovo Systems.
- **ValidBridge Cloud** — Some EE features (like Payments) are available on lower-tier plans. Others (SSO, SCORM, Audit Logs) require an Enterprise plan.

## Enterprise Features

- **[Single Sign-On (SSO)](/enterprise/sso)** — Authenticate users through WorkOS (which brokers SAML, Okta, Azure AD, and more) or any OIDC-compatible provider via the Custom OIDC integration.
- **[Audit Logs](/enterprise/audit-logs)** — A full audit trail of all platform activity for compliance and security monitoring, with filtering and CSV export.
- **[SCORM](/enterprise/scorm)** — Import and run SCORM 1.2 and 2004 learning packages from authoring tools like Articulate Storyline and Adobe Captivate.
