# Environment Variables

This page is the deployment reference for ValidBridge environment variables. The backend
loads `apps/api/config/config.yaml` first, then overrides matching settings from the
environment. The web app reads `NEXT_PUBLIC_*` values from runtime config or `process.env`.
The CLI-generated `.env` file is the recommended way to configure a self-hosted instance.

<Callout type="info">
Values shown as "required" have no safe production fallback. Values shown as "unset" are
optional: the feature stays disabled or uses a runtime fallback when the variable is missing.
</Callout>

## Instance and hosting

| Variable | Description | Type | Default / required | Used by |
| --- | --- | --- | --- | --- |
| `VALIDBRIDGE_SITE_NAME` | Instance name returned by the API. | string | `ValidBridge` | API |
| `VALIDBRIDGE_SITE_DESCRIPTION` | Short instance description returned by the API. | string | `ValidBridge is a platform tailored for learning experiences.` | API |
| `VALIDBRIDGE_CONTACT_EMAIL` | Contact email for the instance. | email | `hello@validbridge.co.ke` | API |
| `VALIDBRIDGE_ENV` | Environment label for backend and Sentry reporting. | string | `dev` | API, Web |
| `VALIDBRIDGE_DEVELOPMENT_MODE` | Enables development-only API behavior such as docs routes and EE dev override. | boolean | `false` | API, CLI |
| `VALIDBRIDGE_SAAS` | Enables SaaS deployment mode, plan gating, and platform endpoint warnings. | boolean | `false` | API |
| `VALIDBRIDGE_SELF_HOSTED` | Legacy self-hosting flag used in tenancy inference. Prefer `VALIDBRIDGE_TENANCY`. Accepts `true`/`1`/`yes`/`on` (case-insensitive); anything else is off. Previously any non-empty value enabled it, including the string `false`. | boolean | unset (off) | API |
| `VALIDBRIDGE_USE_DEFAULT_ORG` | Legacy default-org flag used in tenancy inference. Prefer `VALIDBRIDGE_TENANCY`. Accepts `true`/`1`/`yes`/`on` (case-insensitive); anything else is off. Previously any non-empty value enabled it, including the string `false`. | boolean | unset (off) | API |
| `VALIDBRIDGE_TENANCY` | Selects `single` host tenancy or `multi` subdomain tenancy. Multi-tenancy requires EE or SaaS mode. | enum: `single`, `multi` | `single` unless inferred as multi-tenant | API, EE CLI |
| `VALIDBRIDGE_DOMAIN` | Public domain used for org routing, cookie decisions, and custom-domain CNAME targets. Include the port for local development. | hostname | `localhost:3000` | API, CLI |
| `VALIDBRIDGE_FRONTEND_DOMAIN` | Frontend host used by the API when it needs the public frontend domain separately from the backend host. | hostname | `localhost:3000` | API, EE CLI |
| `VALIDBRIDGE_SSL` | Backend-side SSL flag: picks `https` vs `http` for generated links (password reset, email verification, invites, magic links, SSO redirect, media URLs). Accepts `true`/`1`/`yes`/`on` (case-insensitive); anything else is off. Previously any non-empty value enabled it, including the string `false` — check your value before upgrading. | boolean | `false` | API |
| `VALIDBRIDGE_PORT` | Backend port. Local config defaults to `1338`; the production CLI template emits `9000`. | integer | `1338` locally, `9000` in generated Docker installs | API, CLI, API container |
| `VALIDBRIDGE_ALLOWED_ORIGINS` | Comma-separated CORS allowlist. | CSV of URLs | `http://localhost:3000,http://localhost:3001` | API |
| `VALIDBRIDGE_ALLOWED_REGEXP` | Additional CORS origin regex used by multi-tenant deployments. | regex string | `\b((?:https?://)[^\s/$.?#].[^\s]*)\b` | API |
| `VALIDBRIDGE_COOKIE_DOMAIN` | Cookie domain for auth cookies. Use a leading dot only when subdomains must share auth. | hostname | `.localhost` | API, CLI |
| `VALIDBRIDGE_COOKIE_DOMAIN_ALLOW_BROAD` | Acknowledges intentionally broad cookie domains such as `.example.com` and silences the safety warning. | boolean | `false` | API, EE CLI |
| `VALIDBRIDGE_CUSTOM_DOMAIN_DEV_MODE` | Skips DNS verification for all custom domains and marks them verified immediately. Development/testing only. | boolean | `false` | API |
| `VALIDBRIDGE_PUBLIC` | Docker build argument that produces a community build by excluding non-community code. | boolean | `false` | Dockerfiles (root, API, Web) |
| `VALIDBRIDGE_PLATFORM_URL` | Base URL for ValidBridge platform links, upgrade URLs, and email allowlist checks. | URL | unset; backend flows fall back to `https://www.validbridge.co.ke` and the web token-exchange to `https://validbridge.co.ke` | API, Web |
| `VALIDBRIDGE_PLATFORM_API_KEY` | Shared secret for platform-only internal endpoints such as packs. When unset, those endpoints reject every request with a 403 and the API logs an error on the first rejected request. | secret string | required for SaaS/platform endpoints | API |
| `CLOUD_INTERNAL_KEY` | Shared secret for SaaS-internal endpoints (custom-domain sync and the `cloud_internal` router). When unset, those endpoints reject every request and the API logs a startup warning. | secret string | unset; required for SaaS custom-domain provisioning | API |

## Database, Redis, and collaboration

| Variable | Description | Type | Default / required | Used by |
| --- | --- | --- | --- | --- |
| `VALIDBRIDGE_SQL_CONNECTION_STRING` | PostgreSQL connection string for the API and Alembic migrations. | PostgreSQL URL | `postgresql://validbridge:validbridge@localhost:5432/validbridge`; production installs should set it | API, API migrations, CLI |
| `VALIDBRIDGE_DB_URL` | Fallback database URL for the standalone `apps/api/scripts/migrate.py` migration helper when `DATABASE_URL` is unset. | PostgreSQL URL | `postgresql://validbridge:validbridge@localhost:5432/validbridge` | API migration script |
| `VALIDBRIDGE_PGBOUNCER` | Forces PgBouncer/Supavisor-safe asyncpg settings even when the URL does not reveal a pooler. | boolean | `false` | API |
| `VALIDBRIDGE_REDIS_CONNECTION_STRING` | Redis URL for the API cache/session/event clients. | Redis URL | `redis://localhost:6379/validbridge` | API, CLI |
| `VALIDBRIDGE_REDIS_URL` | Redis URL for the collaboration server. | Redis URL | `redis://localhost:6379`; CLI setup emits `redis://redis:6379` | Collab, CLI |
| `VALIDBRIDGE_API_URL` | API base URL used by the collaboration server. | URL | `http://localhost:8000`; generated compose sets `http://localhost:9000` | Collab, CLI |

## Security, setup, and auth

| Variable | Description | Type | Default / required | Used by |
| --- | --- | --- | --- | --- |
| `VALIDBRIDGE_AUTH_JWT_SECRET_KEY` | JWT signing key shared by the API and collaboration server. Must be at least 32 characters. | secret string | required | API, Collab, CLI |
| `VALIDBRIDGE_INITIAL_ADMIN_EMAIL` | Initial admin email used by the API install command and generated `.env` files. | email | `admin@school.dev` for the API install command; CLI setup writes the chosen email | API, CLI |
| `VALIDBRIDGE_INITIAL_ADMIN_PASSWORD` | Initial admin password used by the API install command and generated `.env` files. | secret string | required for install/bootstrap | API, CLI |
| `VALIDBRIDGE_INITIAL_ORG_NAME` | Initial organization display name used during install. | string | `Default Organization` | API, CLI |
| `VALIDBRIDGE_INITIAL_ORG_SLUG` | Initial organization slug used during install. | slug string | `default` | API, CLI |
| `VALIDBRIDGE_GOOGLE_CLIENT_ID` | Google OAuth client ID used by web auth proxy routes. The API also accepts it as a fallback audience for backend token validation. | string | unset unless Google OAuth is enabled | Web, CLI, API |
| `VALIDBRIDGE_GOOGLE_CLIENT_SECRET` | Google OAuth client secret used by the web token exchange route. | secret string | unset unless Google OAuth is enabled | Web, CLI |
| `VALIDBRIDGE_GOOGLE_OAUTH_CLIENT_ID` | Expected Google OAuth audience for backend ID-token validation. Required to enable Google sign-in: if neither this nor `VALIDBRIDGE_GOOGLE_CLIENT_ID` is set the audience cannot be checked and Google sign-in is refused. | string | unset | API |

## Web runtime

| Variable | Description | Type | Default / required | Used by |
| --- | --- | --- | --- | --- |
| `NEXT_PUBLIC_VALIDBRIDGE_API_URL` | Explicit API URL for frontend API calls. If unset, the web app derives it from `NEXT_PUBLIC_VALIDBRIDGE_BACKEND_URL`. | URL | derived as `{backend}/api/v1/` | Web, CLI |
| `NEXT_PUBLIC_VALIDBRIDGE_BACKEND_URL` | Backend base URL used by the web app and server-side auth proxy routes. | URL | `http://localhost/` in config helpers; local dev checker writes `http://localhost:1338/` | Web, CLI |
| `NEXT_PUBLIC_VALIDBRIDGE_DOMAIN` | Public frontend domain. The web app can also fall back to runtime cookies set by the backend. | hostname | `localhost` or runtime cookie fallback | Web, CLI |
| `NEXT_PUBLIC_VALIDBRIDGE_TOP_DOMAIN` | Top-level/root domain used for cookie and subdomain helpers. | hostname | derived from `NEXT_PUBLIC_VALIDBRIDGE_DOMAIN` when unset | Web, CLI |
| `NEXT_PUBLIC_VALIDBRIDGE_MULTI_ORG` | Legacy public multi-org flag generated by the CLI. Backend `VALIDBRIDGE_TENANCY` is authoritative for current behavior. | boolean | `false` | CLI, legacy Web config |
| `NEXT_PUBLIC_VALIDBRIDGE_DEFAULT_ORG` | Default organization slug used by frontend routing fallbacks. | slug string | `default` | Web, CLI |
| `NEXT_PUBLIC_VALIDBRIDGE_HTTPS` | Selects `https://` instead of `http://` in frontend URL helpers. | boolean | `false` | Web, CLI |
| `NEXT_PUBLIC_VALIDBRIDGE_MEDIA_URL` | Base URL for direct media links. If unset, media URLs use the backend URL. | URL | unset, falls back to backend URL | Web |
| `NEXT_PUBLIC_UNSPLASH_ACCESS_KEY` | Unsplash API access key for the in-editor Unsplash image picker (course thumbnails, board/community thumbnails, editor image blocks, and more). The picker still renders when unset, but Unsplash searches return nothing. | string | unset | Web, CLI |
| `NEXT_PUBLIC_VALIDBRIDGE_PLATFORM_URL` | Browser-safe platform base URL for upgrade and auth exchange flows. | URL | unset | Web |
| `NEXT_PUBLIC_VALIDBRIDGE_SENTRY_DSN` | Browser/server Sentry DSN for the web app. | URL | unset | Web |
| `NEXT_PUBLIC_VALIDBRIDGE_ENV` | Web Sentry environment label. | string | `dev` | Web |

| `VALIDBRIDGE_AI_EMBEDDING_MODEL` | Optional embedding model override. | model id | provider default, such as `gemini-embedding-001`, `text-embedding-3-small`, or `nomic-embed-text` | API |

## Payments

| Variable | Description | Type | Default / required | Used by |
| --- | --- | --- | --- | --- |
| `VALIDBRIDGE_PAYSTACK_SECRET_KEY` | Platform-level fallback Paystack secret key. Each organization normally stores its own key under **Payments → Configuration**; this is only used for organizations that have none. | secret string | unset | API |
| `VALIDBRIDGE_PAYSTACK_PUBLIC_KEY` | Platform-level fallback Paystack public key. | string | unset | API |

Paystack webhooks are sent to `/api/v1/payments/paystack/webhook` and verified with the organization's secret key (HMAC-SHA512); there is no separate webhook secret.

## Related generated variables

These variables do not use the `VALIDBRIDGE_` prefix, but the CLI writes them into the same
`.env` file and several services require them.

| Variable | Description | Type | Default / required | Used by |
| --- | --- | --- | --- | --- |
| `HTTP_PORT` | Public HTTP port chosen during CLI setup. | integer | setup choice | CLI-generated compose |
| `NEXTAUTH_URL` | Base URL for NextAuth-compatible auth helpers. | URL | generated from the configured domain | CLI, doctor |
| `NEXTAUTH_SECRET` | Secret used by NextAuth-compatible auth helpers. | secret string | generated by CLI setup | CLI, doctor |
| `COLLAB_INTERNAL_KEY` | Shared key for API-to-collaboration-server internal auth. | secret string | required for dev and production collab auth | API, Collab, CLI |
| `NEXT_PUBLIC_COLLAB_URL` | Public WebSocket URL for the collaboration server. | WebSocket URL | generated from the configured domain | Web, CLI |
| `COLLAB_PORT` | Local collaboration server port. | integer | `4000` in local dev checker | Collab, CLI dev |
| `COLLAB_TRUST_PROXY` | Set to `true` when the collaboration server runs behind a reverse proxy so client IPs (used for WebSocket rate limiting) are read from `X-Forwarded-For`. | boolean | `false` | Collab |
| `POSTGRES_USER` | PostgreSQL user for generated non-external database installs. | string | `validbridge` | CLI-generated compose |
| `POSTGRES_PASSWORD` | PostgreSQL password for generated non-external database installs. | secret string | generated by CLI setup | CLI-generated compose |
| `POSTGRES_DB` | PostgreSQL database name for generated non-external database installs. | string | `validbridge` | CLI-generated compose |

## Full example

```env filename=".env" copy
# Domain and hosting
VALIDBRIDGE_DOMAIN=learn.example.com
HTTP_PORT=443
NEXT_PUBLIC_VALIDBRIDGE_BACKEND_URL=https://learn.example.com/
NEXT_PUBLIC_VALIDBRIDGE_API_URL=https://learn.example.com/api/v1/
NEXT_PUBLIC_VALIDBRIDGE_DOMAIN=learn.example.com
NEXT_PUBLIC_VALIDBRIDGE_TOP_DOMAIN=example.com
NEXT_PUBLIC_VALIDBRIDGE_HTTPS=true
NEXT_PUBLIC_VALIDBRIDGE_DEFAULT_ORG=default

# Backend
VALIDBRIDGE_SQL_CONNECTION_STRING=postgresql://validbridge:change-me@db:5432/validbridge
VALIDBRIDGE_REDIS_CONNECTION_STRING=redis://redis:6379/validbridge
VALIDBRIDGE_COOKIE_DOMAIN=.example.com
VALIDBRIDGE_PORT=9000

# Security and bootstrap
VALIDBRIDGE_AUTH_JWT_SECRET_KEY=replace-with-at-least-32-random-characters
VALIDBRIDGE_INITIAL_ADMIN_EMAIL=admin@example.com
VALIDBRIDGE_INITIAL_ADMIN_PASSWORD=change-this-password
VALIDBRIDGE_INITIAL_ORG_NAME=Default Organization
VALIDBRIDGE_INITIAL_ORG_SLUG=default

# Collaboration
COLLAB_INTERNAL_KEY=replace-with-random-shared-secret
VALIDBRIDGE_REDIS_URL=redis://redis:6379
NEXT_PUBLIC_COLLAB_URL=wss://learn.example.com/collab

# AI, email, and storage
VALIDBRIDGE_IS_AI_ENABLED=False
VALIDBRIDGE_EMAIL_PROVIDER=resend
VALIDBRIDGE_CONTENT_DELIVERY_TYPE=filesystem
```
