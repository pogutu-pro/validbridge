# Maintenance Overview

Keeping your self-hosted ValidBridge instance healthy requires periodic maintenance. Docker Compose provides the tools for the most common maintenance tasks.

## Maintenance Tasks

### [Updates](/self-hosting/maintenance/updates)

Keep ValidBridge up to date with the latest features, improvements, and security patches using `validbridge update`.

### [Backups](/self-hosting/maintenance/backups)

Protect your data with regular backups of the database and uploaded content using `validbridge backup`.

### [Monitoring](/self-hosting/maintenance/monitoring)

Monitor the health and performance of your instance using `validbridge status` and `validbridge logs`.

### [Troubleshooting](/self-hosting/maintenance/troubleshooting)

Diagnose and resolve common issues with your self-hosted instance.
