# Using ValidBridge

This is the **user guide** — a complete, section-by-section explanation of every feature in ValidBridge, written for the people who use it. It is task-oriented: each page tells you what a feature is for and exactly how to use it.

If you are looking for installation, configuration or architecture, see the [Self Hosting](/self-hosting) and [Developers](/developers) sections instead.

<Callout type="info">
This guide mirrors the **Help Center** built into the platform. Open **Help** in the top bar or the dashboard sidebar to read the same material without leaving the app.
</Callout>

## How this guide is organised

The guide is split by the kind of work you do:

### [Getting Started](/using/getting-started)
Accounts, the four default roles, how the navigation works, the command palette, and how to get help.

### [Learning](/using/learning)
Everything a learner does — browsing and enrolling in courses, working through activities, submitting assignments, using the AI Copilot, your Trail, certificates, discussions, boards, podcasts and search.

### [Teaching](/using/teaching)
Building courses: creating a course, the block editor, chapters and activities, assignments and grading, AI authoring tools, boards, podcasts and course analytics.

### [Administering](/using/administering)
Managing users, roles and permissions, user groups, organization settings, branding and the landing page, payments, and the developers tools (API, automations, custom domains, SEO and SSO).

### [Troubleshooting & FAQ](/using/troubleshooting)
Quick answers to the most common problems.

<Callout type="tip">
New here? Read [Getting Started](/using/getting-started), then jump to the section for your role. Everything is cross-linked, so you can move sideways whenever a topic interests you.
</Callout>

## A quick map of the platform

| Concept | What it means |
| --- | --- |
| **Organization** | The top-level workspace. It owns all courses, users, settings and branding. |
| **Course** | A program of study, made up of chapters. |
| **Chapter** | A module inside a course, containing activities. |
| **Activity** | One piece of learning content — a rich page, video, document or assignment. |
| **Trail** | A learner's personal progress record across every course they have started. |
