# Assignments

An **assignment** is a gradable activity. Your instructor sets a prompt, optionally a due date, and one or more **tasks** that tell you what to submit. This page explains how to submit work and understand your results.

## Opening an assignment

Inside a course, an assignment appears in the activity list like any other activity, usually with a badge showing whether it is pending, submitted or graded. Open it to see:

- **The prompt** — what the instructor is asking for.
- **Tasks** — the specific things you must submit.
- **Due date** — when it is expected (if one was set).
- **Attempts** — how many submissions are allowed.
- **Grade** — shown once your instructor has reviewed your work.

## Task types

An assignment can contain several tasks. Each task is one of these types:

| Task type | What you do |
| --- | --- |
| **File submission** | Upload one or more files as your answer. |
| **Quiz** | Answer a set of multiple-choice / single-choice questions. |
| **Short answer** | Type a free-text response. |
| **Number** | Enter a numeric answer, sometimes within a tolerance. |
| **Code** | Write and optionally run code in a sandboxed editor. |
| **Form** | Fill in a structured form defined by the instructor. |

You complete every task in the assignment, then submit the whole thing.

## Submitting your work

1. Open the assignment and read the prompt carefully.
2. Work through each task. Your answers are saved as you go.
3. When everything is filled in, review it once more.
4. Click **Submit**. If the assignment is auto-graded (for example a quiz), your score may appear immediately; otherwise it enters the grading queue.
5. Wait for your instructor to review and grade. You will see the result and any feedback on the assignment page.

<Callout type="warning">
Check the **attempts** setting before you submit. If only one attempt is allowed, you cannot edit or resubmit after sending, so make sure it is right first.
</Callout>

## Deadlines and late work

An assignment may have a due date. Submitting before the deadline is recorded as **on time**; after it, your submission is marked **late**. Whether late work is accepted, and whether it is penalised, is up to your instructor. If you miss a deadline, submit anyway and message your instructor — many will still grade it.

## Grades and feedback

Once graded, an assignment shows:

- **Your score** — for auto-graded tasks this can be immediate; for reviewed tasks it comes after your instructor grades it.
- **Feedback** — comments written by your instructor, and any per-task feedback.
- **Status** — graded, returned for revision, or pending.

For courses that issue certificates, assignment grades typically count toward completion.

## If something goes wrong

- **Upload fails** — check the file size and type allowed, and try again on a stable connection.
- **The submit button is disabled** — you likely have an unfinished required task. Scroll through and complete it.
- **You cannot resubmit** — your attempts are used up. Contact your instructor and ask them to reopen the submission.
