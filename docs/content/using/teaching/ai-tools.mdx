# AI Authoring Tools

ValidBridge includes optional AI features that help you build content faster and help learners understand it. Everything AI is controlled by your organization's administrator — see [Organization Settings](/using/administering/organization-settings). An admin can switch AI on or off for the whole organization and, separately, turn the learner-facing Copilot on or off.

## AI in the editor

### Magic blocks

A **magic block** is a content block you generate with AI from inside the [Course Editor](/using/teaching/editor):

1. Insert a magic block from the block menu (`/`).
2. Describe what you want — a paragraph, an explanation, an example, a set of questions.
3. Generate, then review the result. Keep it, edit it, or regenerate.
4. Save the block into the page like any other.

Magic blocks are a starting point, not a finished page. Always review generated text for accuracy and tone before publishing.

### AI selection tools

Highlight text in the editor to reveal AI actions that can **rewrite**, **shorten**, **expand** or **rephrase** the selection. These are useful for tightening a paragraph or adjusting the reading level.

### AI explanations for learners

Inside an activity, learners can ask AI to explain a passage or concept. This is part of the [Copilot](/using/learning/ai-copilot) experience.

## AI for assignments

When building an [assignment](/using/teaching/assignments), you can use **Generate tasks with AI**: describe the assignment and AI proposes a set of tasks (for example a quiz with questions) that you then edit. It is a fast way to produce a first draft of a quiz.

## Creating a course with AI

When creating a course, an AI-assisted flow can propose a course structure — chapters and activities — from a description of the subject. You review and edit the result before publishing. Use it to get past the blank page, then apply your own expertise.

<Callout type="warning">
AI can be confidently wrong and may produce text that reads well but is inaccurate. You are responsible for everything you publish. Review AI output for correctness, bias and licensing before it reaches learners.
</Callout>

## What to use AI for — and what not to

**Good uses**

- Drafting explanations, summaries and practice questions.
- Rephrasing at a different reading level.
- Generating a course skeleton to react to.

**Poor uses**

- Publishing AI text unreviewed.
- Using AI to grade subjective work without human oversight.
- Replacing your own subject-matter judgement.

## Turning AI on or off

Administrators control AI in **Dashboard → Organization settings → AI**:

- **AI enabled** — turns the whole AI feature set on or off for the organization.
- **Copilot enabled** — controls the learner-facing assistant specifically.

If AI is disabled, the magic blocks, AI selection tools and Copilot do not appear.
