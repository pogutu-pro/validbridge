# Assignments & Grading

An **assignment** is the gradable activity type. You set a prompt, add **tasks** that define what learners submit, then review and grade their work. This page covers the whole cycle.

## Creating an assignment

Assignments belong to a course and live inside a chapter like any other activity.

1. Open the **Content** tab of a course and open a chapter.
2. Choose **Add activity** and select **Assignment**.
3. Name it, and open it to configure the prompt and tasks.

You can also reach assignments from the **Assignments** entry in the dashboard, which lists everything across your courses.

## Anatomy of an assignment

- **Prompt** — the instructions learners read first.
- **Tasks** — the specific things learners must submit.
- **Due date** — when work is expected.
- **Grading** — how the assignment is scored and which tasks count.
- **Submissions** — the learner work you review.

## Task types

Every task is one of six types:

| Task type | What learners submit | Grading |
| --- | --- | --- |
| **Quiz** | Answers to multiple/single-choice questions. | Can be auto-graded. |
| **File submission** | One or more uploaded files. | Manual or per-file. |
| **Short answer** | A free-text response. | Manual. |
| **Number answer** | A numeric value, optionally with tolerance. | Can be auto-checked. |
| **Code** | Code written in an editor. | Manual (or run in a sandbox). |
| **Form** | A structured form you define. | Manual or auto. |

To add a task: open the assignment's editor, choose **New task**, and pick a type. Configure it in the task editor — for a quiz, write the questions and correct answers; for a file task, set the allowed file types and size.

<Callout type="tip">
Mix task types. A short quiz plus a file submission lets learners check their understanding and then show applied work.
</Callout>

## Configuring grading

- **Auto-graded tasks** produce a score the moment a learner submits — ideal for quizzes and numeric answers.
- **Manual tasks** wait for you in the grading queue.
- Set **per-task weighting** so the overall grade reflects what matters most.
- Where supported, give learners **feedback** per task as well as an overall comment.

## Reviewing submissions

Open the assignment's **Submissions** view to see who has submitted and what state each submission is in (submitted, graded, returned).

1. Open a learner's submission.
2. Read their work task by task.
3. Enter a grade and write feedback.
4. Save. The learner sees the result on their assignment page.

You can usually filter by status so you can focus on ungraded work first.

## Analytics

Each assignment has an **Analytics** view showing completion and scores across the cohort. Use it to spot a question everyone missed, or a task that is confusing.

## Good practice

- State the grading criteria in the prompt so learners know what "good" looks like.
- Keep due dates realistic and visible.
- Grade consistently — read a few submissions before assigning the first mark.
- Return feedback even when a score is auto-computed; learners value the explanation.
