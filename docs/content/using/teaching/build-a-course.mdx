# Building a Course

A course is a container: it holds **chapters**, and each chapter holds **activities**. This page takes you from an empty dashboard to a structured course.

## Creating a course

1. Open the **Dashboard** and go to **Courses**.
2. Choose **New course**.
3. Give it a **name** and a short **description**. The description is what learners see in the catalogue, so make it clear.
4. Add a **thumbnail** — a clean, well-lit image reads best in the catalogue.
5. Fill in the **about** information: what learners will gain, any prerequisites, and the estimated effort.
6. Save. The course is created as a **draft** and is not visible to learners yet.

<Callout type="tip">
Write the description and learning outcomes before you start creating chapters. They keep the course focused and give learners a reason to enrol.
</Callout>

## The course settings tabs

Once the course exists, its page has a set of tabs. What you can see depends on your permissions and your plan.

| Tab | What it controls |
| --- | --- |
| **General** | Name, description, thumbnail, tags and course metadata. |
| **Content** | Chapters and activities — where you actually build the course. |
| **Access** | Who can find and enrol in the course: public/private, enrolment rules, offers and user groups. |
| **Contributors** | Other people who can edit the course, and what each may do. |
| **SEO** | Search-engine title, description and sharing image (on supported plans). |
| **Certification** | The certificate issued when learners complete the course (on supported plans). |
| **Analytics** | How learners are progressing (on supported plans). |

## Adding chapters

Chapters are the top-level sections of a course — think of them as modules or weeks.

1. Open the **Content** tab.
2. Choose **Add chapter**.
3. Name the chapter and give it a short description.
4. Save. The chapter appears in the content tree.

Order matters: learners move through chapters from top to bottom, so arrange them logically. You can reorder chapters at any time.

## Adding activities

Activities are the individual pieces of learning inside a chapter. ValidBridge supports four kinds:

| Activity type | Use it for |
| --- | --- |
| **Page** | Rich written content — the main workhorse. |
| **Video** | Watching a video, with a transcript where available. |
| **Document** | An inline PDF or similar document. |
| **Assignment** | Graded work that learners submit. |

To add one:

1. Open a chapter and choose **Add activity**.
2. Pick the activity type.
3. Give it a **name** — this is what learners see in the activity list, so make it descriptive.
4. Save, then open it to start writing. Page content is built in the [Course Editor](/using/teaching/editor).

## Ordering and moving

Drag activities to reorder them within a chapter, and move them between chapters as the course grows. Learners follow the order you set, so keep the sequence intentional.

## Making the course yours

- **Access** — decide whether the course is open, invite-only or paid.
- **Contributors** — bring in co-authors and decide who can publish.
- **Certification** — attach a certificate so completers receive something.
- **SEO** — improve how the course appears when shared.

When you are ready for learners to see it, move on to [Publishing & Sharing](/using/teaching/publishing).
