# The Course Editor

The **Course Editor** is where you write the content of a **Page** activity. It is a block editor: you build the page from content blocks, each of which you can move, edit or delete on its own.

## Opening the editor

1. Open a **Page** activity from the Content tab of a course.
2. Click into the page body.
3. Start typing, or open the block menu to insert something richer.

Changes save as you work, so you rarely need to think about saving. A status indicator tells you when the page is saved.

## Adding blocks

There are two ways to insert a block:

- **Type a slash** — press `/` on an empty line to open the block menu, type to filter, and press Enter.
- **Use the add control** — click the `+`/insert handle at the start of a line and pick a block.

Each block also has a **drag handle**, so you can reorder blocks by dragging them.

## The block library

### Text and structure

- **Paragraph** — ordinary body text.
- **Heading** — section titles at several levels; use these to build the page's outline.
- **Bulleted and numbered lists**.
- **Quote** and **Divider**.
- **Callout** — a highlighted box for tips, warnings and key points.
- **Math equation** — typeset mathematical notation.

### Media

- **Image** — upload or pick from the course media library.
- **Video** — embed a video and play it inline.
- **Audio** — embed an audio clip.
- **PDF** — present a PDF inline.
- **Web preview / embed objects** — embed an external page or object.
- **H5P** — embed interactive H5P content.

### Interaction and assessment

- **Quiz** — add questions directly into a page for self-check.
- **Code playground** — an editable, runnable code block.
- **Flipcard** — a click-to-reveal card, good for definitions.
- **Scenarios** — branching, choose-your-path content.
- **Badges**, **Buttons** and **Users** — richer ways to surface people and calls to action.

### Media library

- **Library** — pull in an item from the organization's media library so you can reuse an asset across courses without re-uploading it.

### AI

- **Magic blocks** — generate a block, or a whole passage, with AI. See [AI Authoring Tools](/using/teaching/ai-tools).

## Formatting text

Select text to reveal the inline toolbar: **bold**, *italic*, underline, strikethrough, links, inline code and text colour. Use headings rather than bold paragraphs to organise a page — learners and screen readers rely on the heading structure.

## Reusing and moving content

- **Drag** a block by its handle to move it.
- **Copy** a block and paste it elsewhere, including into another activity.
- **Library** blocks let several courses share one asset.

## Good practice

- Lead each page with a short paragraph that says what the page covers.
- Break long pages into headings and chapters rather than one giant scroll.
- Use callouts sparingly — if everything is highlighted, nothing is.
- Add a self-check quiz in long pages so learners can test themselves.
- Preview the page as a learner before you publish, to catch broken media and layout problems.

<Callout type="warning">
Delete a media block before deleting the file it points at from the media library. Removing a file that a page still references leaves a broken block until you replace it.
</Callout>
