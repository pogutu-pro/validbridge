# Publishing & Sharing

Building a course is only half the job — learners have to find it and be able to join. This page covers course states, access rules and how to get a course in front of the right people.

## Course states

A course moves through a few states:

| State | Meaning |
| --- | --- |
| **Draft** | Still being written. Not visible to learners. |
| **Published** | Live and visible according to its access rules. |
| **Private** | Published, but only reachable by people with access. |
| **Archived** | Retired. Kept for records, no longer promoted. |

You decide when a course becomes published. Keep it a draft until the content, access and certificate are all correct.

## Access rules

The **Access** tab controls who can find and join the course:

- **Public** — listed in the catalogue; anyone with access to the organization can see it.
- **Private / unlisted** — only reachable by direct link or by people with access.
- **Enrolment** — whether learners self-enrol, need approval, or are added by an admin.
- **Offers and groups** — restrict access to a paid offer or to a [user group](/using/administering/users-and-roles). This is how you run cohort-based or paid programs.

<Callout type="warning">
Changing access takes effect immediately. Before you switch a course to public, check the content is finished and the description is accurate — learners may find it within seconds.
</Callout>

## SEO and sharing

On supported plans the **SEO** tab lets you set the title, description and sharing image used when the course is linked on social media or found by search engines. A clear title and a one-sentence description make a large difference to whether people click.

## Certificates

Attach a **certificate** on the **Certification** tab so learners receive proof of completion. You control the wording and the rules for earning it. See [Progress & Certificates](/using/learning/progress-and-certificates) for what learners see.

## Contributors

Use the **Contributors** tab to bring in co-authors. Give each contributor the access they need — some may write content while others review and publish. Contributors only see the courses they are added to.

## A pre-publish checklist

- [ ] The description says who the course is for and what they will gain.
- [ ] Every chapter and activity is complete, with no placeholder text.
- [ ] Media loads, and links open.
- [ ] Access rules match your intent.
- [ ] A certificate is attached, if one is expected.
- [ ] SEO fields are filled in, if available.
- [ ] You have previewed the course as a learner.

## Announcing the course

- Share the course link directly, or publish it in a **community**.
- Add it to a **collection** so it appears in curated listings.
- Create a companion **podcast** or **board** to build engagement.
